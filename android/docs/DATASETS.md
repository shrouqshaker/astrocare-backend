# Datasets and references — research manifest

All 14-day demo readings were **synthetically generated** and are not derived from NASA astronaut data. Candidate datasets are not included as raw downloadable data here.

| Source | Data/role | Access/verification | Used in demo |
|---|---|---|---|
| NASA OSDR — https://osdr.nasa.gov | Space biological / physical research context | Confirm individual dataset relevance and access | Reference only |
| NASA NLSP — https://nlsp.nasa.gov/explore | Spaceflight human life-sciences catalog | Some human records restricted | Reference only |
| NASA HRP — https://www.nasa.gov/hrp/hazards/ | Spaceflight health hazard background | Public contextual information | Reference only |
| UTMB actigraphy — via NASA NLSP | Bed-rest/sleep research | Dataset access and reuse need confirmation | No |
| BIDMC — https://physionet.org/content/bidmc/1.0.0/ | Human PPG, respiration, SpO2-related data | Verify data rights and processing needs | No |
| Sleep-EDF — https://physionet.org/content/sleep-edfx/1.0.0/ | Human sleep research | Verify licensing | No |
| WESAD — https://archive.ics.uci.edu/dataset/465/wesad | Human wearable stress signals | Verify licensing | No |
| MedlinePlus — https://medlineplus.gov/ency/article/002341.htm | General vital signs background | Verify exact medical guide claims | Reference only |
| FDA — https://www.fda.gov/medical-devices/products-and-medical-procedures/pulse-oximeters | Pulse oximeter context and limitations | Verify exact guide claims | Reference only |
| AHA — https://www.heart.org/en/health-topics/heart-attack/warning-signs-of-a-heart-attack | Chest-pain warning signs | Not an astronaut emergency protocol | Reference only |

Source `verified` flags in the JSON package are conservative and must not be treated as medical approval.
